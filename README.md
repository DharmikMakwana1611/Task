# Task
A full stack web application with manage categories with Create, Read, Update and Delete entries 

The project is build using React, Node, Express and MongoDB

## Project Structure

Transactions-Manager/<br />
│<br />
├── Backend/ # Backend (Node.js, Express, MongoDB) <br />
├── frontend/ # Frontend (React)<br />
├── .gitignore<br />
├── README.md,br />

 -> Features

- Add new Categories
- View categories in a table
- Update existing category
- Delete category
- Clean and modern UI
- Separate frontend and backend structure

## Tech Stack

### Frontend
- React
- TailwindCSS (custom styling)

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation & Setup

###  Clone the repository<br />
Terminal<br />
git clone https://github.com/DharmikMakwana1611/Task.git<br />
cd Task<br />

 Backend Setup<br />
cd Backend<br />
npm install<br />

Start backend server:<br />
npm start<br />

Backend will run on:<br />
http://localhost:5000<br />

Frontend Setup<br />
Open a new terminal:<br />
cd frontend<br />
npm install<br />
npm start<br />

Frontend will run on:<br />
http://localhost:3000<br />

Make sure both backend and frontend servers are running<br />

Open browser and go to:<br />
http://localhost:3000<br />
